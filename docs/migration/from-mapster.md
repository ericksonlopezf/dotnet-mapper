# Migration Guide: Moving from Mapster to EricksonLopez.Mapper

How to migrate existing Mapster configurations to `EricksonLopez.Mapper` or use the dedicated `EricksonLopez.Mapper.Mapster` bridge adapter.

---

## 1. Using the Mapster Bridge Package

For existing applications with extensive Mapster `TypeAdapterConfig`, install the bridge package:

```bash
dotnet add package EricksonLopez.Mapper.Mapster
```
