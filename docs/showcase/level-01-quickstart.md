## 1. Package Installation

Install the core package via the .NET CLI or Package Manager:

```bash
dotnet add package EricksonLopez.Mapper
```

The package includes both the abstractions (`EricksonLopez.Mapper.Abstractions`) and the Roslyn incremental source generator analyzer (`EricksonLopez.Mapper.Generator`).

---

## 2. Minimal Configuration

To declare a mapper, create a `partial` class and decorate it with `[Mapper]`. Inside the class, define a `partial` method specifying the source type as the input parameter and the target type as the return value:

```csharp
using System;
using EricksonLopez.Mapper;

namespace MyProject;

// 1. Domain model and DTO
public class User
{
    public Guid Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public string Email { get; set; } = string.Empty;
}

public class UserDto
{
    public Guid Id { get; set; }
    public string Name { get; set; } = string.Empty;
    public string Email { get; set; } = string.Empty;
}

// 2. Mapper declaration
[Mapper]
public partial class SimpleUserMapper
{
    public partial UserDto Map(User source);
}
```

---

## 3. Emitted C# Source Code

During compilation (`dotnet build`), the generator emits companion file `SimpleUserMapper.g.cs`:

```csharp
// <auto-generated />
#nullable enable
namespace MyProject;

public partial class SimpleUserMapper
{
    public partial UserDto Map(User source)
    {
        if (source == null) throw new ArgumentNullException(nameof(source));

        var target = new UserDto
        {
            Id = source.Id,
            Name = source.Name,
            Email = source.Email,
        };

        return target;
    }
}
```

---

## 4. First Execution

```csharp
var user = new User
{
    Id = Guid.NewGuid(),
    Name = "Erickson Lopez",
    Email = "erickson@example.com"
};

var mapper = new SimpleUserMapper();
UserDto dto = mapper.Map(user);

Console.WriteLine($"Mapped User: {dto.Name} ({dto.Email})");
```

## 5. Basic Dependency Injection

When configuring the ASP.NET Core IoC container:

