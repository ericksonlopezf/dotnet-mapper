# Level 01: QuickStart & Basic Mapping

## 1. Defining a Mapper

To create a compile-time mapper, declare a `public static partial class` annotated with `[Mapper]` containing `partial` method signatures for each mapping transformation:

```csharp
using EricksonLopez.Mapper;

// Source Entity
public sealed record UserEntity(
    Guid Id,
    string FirstName,
    string LastName,
    string Email,
    DateTime CreatedAtUtc);

// Destination DTO
public sealed record UserResponse(
    Guid Id,
    string FirstName,
    string LastName,
    string Email);

// Mapper Declaration
[Mapper]
public static partial class UserMapper
{
    public static partial UserResponse ToResponse(UserEntity entity);
}
```

---

## 2. What Roslyn Generates

Under the hood, the Roslyn Incremental Generator automatically synthesizes the implementation in an internal generated file:

```csharp
// <auto-generated/>
#nullable enable

namespace MyApp.Mappers;

public static partial class UserMapper
{
    [global::System.CodeDom.Compiler.GeneratedCode("EricksonLopez.Mapper.Generator", "1.0.0.0")]
    public static partial UserResponse ToResponse(UserEntity entity)
    {
        if (entity is null)
        {
            return default!;
        }

        return new UserResponse(
            Id: entity.Id,
            FirstName: entity.FirstName,
            LastName: entity.LastName,
            Email: entity.Email
        );
    }
}
```

---

## 3. Key Observations
1. **Direct Constructor Invocation**: No reflection, no dictionaries, no intermediate boxing.
2. **Null-Safety Guard**: When the source instance is null, the method safely returns default.
3. **Deterministic Performance**: Inlined by RyuJIT just like standard handwritten C# code.
