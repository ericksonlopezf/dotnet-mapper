# Getting Started Guide: EricksonLopez.Mapper

Welcome to the official getting started guide for **EricksonLopez.Mapper**, the incremental Roslyn source generator for ultra-high-performance, zero-allocation, **Native AOT**-compatible object mapping in .NET.

---

## 1. Prerequisites

- **.NET SDK:** 8.0, 9.0, or 10.0 installed.
- **IDE:** Visual Studio 2022 (v17.8+), JetBrains Rider (2023.3+), or VS Code with C# Dev Kit.
- **Language:** C# 10 or later (C# 12 / 14 recommended).

---

## 2. Package Installation

In the project where your mappers will reside (typically your Application or Domain/Services layer), install the core metapackage:

```bash
dotnet add package EricksonLopez.Mapper
```

This metapackage automatically includes:
1. `EricksonLopez.Mapper.Abstractions`: Core attributes and contracts such as `[Mapper]`, `[MapProperty]`, and `IConverter<TSource, TDestination>`.
2. `EricksonLopez.Mapper.Generator`: The Roslyn incremental source generator analyzer.

---

## 3. Recommended Project Configuration (`.csproj`)

To view and debug the C# source code emitted by the generator on disk, add the following properties to your `.csproj` file:

```xml
<PropertyGroup>
  <TargetFramework>net10.0</TargetFramework>
  <Nullable>enable</Nullable>
  <ImplicitUsings>enable</ImplicitUsings>
  <!-- Enables physical emission of generated files to disk -->
  <EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>
  <CompilerGeneratedFilesOutputPath>Generated</CompilerGeneratedFilesOutputPath>
</PropertyGroup>

<ItemGroup>
  <!-- Prevents the compiler from compiling generated source files twice -->
  <Compile Remove="Generated\**" />
</ItemGroup>
```

## 4. Creating Your First Mapper

### Step 1: Define Your Models
```csharp
namespace MyApp.Contracts;

public class OrderEntity
{
    public Guid Id { get; set; }
    public string CustomerName { get; set; } = string.Empty;
    public decimal TotalAmount { get; set; }
    public DateTime CreatedAtUtc { get; set; }
}

public sealed record OrderResponseDto(
    Guid Id,
    string CustomerName,
    decimal TotalAmount,
    DateTime CreatedAtUtc
);
```

### Step 2: Declare the Mapper Class
Create an `OrderMapper.cs` file. The class must be **`partial`** and annotated with `[Mapper]`:

```csharp
using EricksonLopez.Mapper;
using MyApp.Contracts;

namespace MyApp.Mappers;

[Mapper]
public partial class OrderMapper
{
    public partial OrderResponseDto ToDto(OrderEntity source);
}
```

### Step 3: Build the Project
Run from your terminal:
```bash
dotnet build
```

The Roslyn generator automatically emits the `OrderMapper.g.cs` implementation file at compile time.

---

## 5. Inspecting the Generated Code

Open the emitted file located at `Generated/EricksonLopez.Mapper.Generator/.../OrderMapper.g.cs`:

```csharp
// <auto-generated />
#nullable enable
namespace MyApp.Mappers;

public partial class OrderMapper
{
    public partial OrderResponseDto ToDto(OrderEntity source)
    {
        if (source == null) throw new ArgumentNullException(nameof(source));

        return new OrderResponseDto(
            source.Id,
            source.CustomerName,
            source.TotalAmount,
            source.CreatedAtUtc
        );
    }
}
```

Key characteristics:
- Standard, clean C# identical to handwritten code.
- Zero `System.Reflection` invocations.
- Zero dynamic delegates or runtime expression tree compilations.
- 100% compatible with **Native AOT** and assembly trimming.

---

## 6. Debugging Generated Code

You can place standard breakpoints directly inside the generated `OrderMapper.g.cs` file in Visual Studio or JetBrains Rider and step through mapping execution during debugging sessions or unit tests.

---

## 7. Dependency Injection (IoC) Registration

### Manual Registration:
```csharp
builder.Services.AddSingleton<OrderMapper>();
```

### Automated Assembly-Wide Registration:
Add to any C# file in your project (e.g., `AssemblyConfig.cs`):
```csharp
using EricksonLopez.Mapper;

[assembly: GenerateMapperRegistration]
```

And in your `Program.cs`:
```csharp
builder.Services.AddGeneratedMappers();
```
