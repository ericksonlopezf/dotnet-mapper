# ELM009: Mapper Uses Dynamic Keyword

| Property | Value |
|---|---|
| **Rule ID** | `ELM009` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types decorated with `[Mapper]` |

---

## 🎯 Rule Description

The C# `dynamic` keyword relies on the Dynamic Language Runtime (DLR) and Microsoft.CSharp runtime binders, which emit IL at runtime and require dynamic code generation. This is fundamentally incompatible with Native AOT compilation and induces GC allocations.

`ELM009` enforces zero usage of `dynamic` in mapping definitions.

---

## ❌ Violation Example

```csharp
[Mapper]
public static partial class PayloadMapper
{
    // Violation: Use of dynamic is prohibited in AOT mapper classes
    public static string ExtractName(dynamic payload) => payload.Name;
}
```

---

## ✅ Compliant Example

```csharp
public sealed record NamedPayload(string Name);

[Mapper]
public static partial class PayloadMapper
{
    public static string ExtractName(NamedPayload payload) => payload.Name;
}
```
