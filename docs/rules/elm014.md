# ELM014: Enum Member Has No Destination Equivalent

| Property | Value |
|---|---|
| **Rule ID** | `ELM014` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Enum-to-enum mappings |

---

## 🎯 Rule Description

Emitted when mapping between two enumeration types where a member in the source enum has no matching member by name or value in the destination enum under strict mapping mode.

---

## ❌ Violation Example

```csharp
public enum SourceStatus { Draft, Submitted, Approved, Archived }
public enum DestStatus { Draft, Submitted, Approved } // Missing Archived

[Mapper]
public static partial class StatusMapper
{
    // Violation: Enum member 'Archived' has no corresponding member in destination enum
    public static partial DestStatus Map(SourceStatus status);
}
```

---

## ✅ Compliant Example (Option A: Explicit Enum Mapping Attribute)

```csharp
[Mapper]
public static partial class StatusMapper
{
    [MapEnumValue(SourceStatus.Archived, DestStatus.Approved)]
    public static partial DestStatus Map(SourceStatus status);
}
```

---

## ✅ Compliant Example (Option B: Relaxed Strict Mapping Mode)

```csharp
[Mapper(StrictMapping = false)]
public static partial class StatusMapper
{
    // Emits warning instead of error, or handles unmatched members gracefully
    public static partial DestStatus Map(SourceStatus status);
}
```
