# ELM018: Duplicate MapProperty Destination Member

| Property | Value |
|---|---|
| **Rule ID** | `ELM018` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Warning` |
| **Enabled by Default** | `true` |
| **Applies to** | Mapping methods with multiple `[MapProperty]` attributes |

---

## 🎯 Rule Description

Emitted when a mapping method declares multiple `[MapProperty]` attributes targeting the same destination member. When duplicate target attributes are declared, the generator uses the last declaration to determine the source mapping.

`ELM018` is emitted as a compile-time warning so the developer is informed of the shadowed configuration and can remove the redundant attribute.

---

## ❌ Violation Example

```csharp
[Mapper]
public static partial class UserMapper
{
    // Warning: Destination member 'DisplayName' is targeted by multiple [MapProperty] attributes
    [MapProperty(nameof(UserEntity.UserName), nameof(UserDto.DisplayName))]
    [MapProperty(nameof(UserEntity.FullName), nameof(UserDto.DisplayName))]
    public static partial UserDto ToDto(UserEntity entity);
}
```

**Compiler Warning:**
> `warning ELM018: Destination member 'DisplayName' is targeted by multiple [MapProperty] attributes. Only the last declaration (source: 'FullName') will be used. Remove the redundant attribute to resolve the ambiguity.`

---

## ✅ Compliant Example

Remove the redundant or superseded `[MapProperty]` attribute to keep the mapping explicit and unambiguous:

```csharp
[Mapper]
public static partial class UserMapper
{
    [MapProperty(nameof(UserEntity.FullName), nameof(UserDto.DisplayName))]
    public static partial UserDto ToDto(UserEntity entity);
}
```
