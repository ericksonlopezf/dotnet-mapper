# ELM013: Invalid Converter Type

| Property | Value |
|---|---|
| **Rule ID** | `ELM013` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types referenced in `[UseConverter]` attributes |

---

## 🎯 Rule Description

Emitted when a type specified in `[UseConverter(typeof(T))]` does not implement the required `IConverter<TSource, TDestination>` contract matching the mapping method's parameter and return types.

---

## ❌ Violation Example

```csharp
public class NotAConverter { }

[Mapper]
public static partial class CustomMapper
{
    // Violation: NotAConverter does not implement IConverter<Src, Dest>
    [UseConverter(typeof(NotAConverter))]
    public static partial Dest Map(Src src);
}
```

---

## ✅ Compliant Example

```csharp
public sealed class DateToStringConverter : IConverter<DateTime, string>
{
    public string Convert(DateTime source) => source.ToString("O");
}

[Mapper]
public static partial class CustomMapper
{
    [UseConverter(typeof(DateToStringConverter))]
    public static partial string FormatDate(DateTime source);
}
```
