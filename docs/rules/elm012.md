# ELM012: Mapper Type Must Be Declared as Partial

| Property | Value |
|---|---|
| **Rule ID** | `ELM012` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Classes or interfaces decorated with `[Mapper]` |

---

## 🎯 Rule Description

Roslyn Source Generators emit code by augmenting existing class or interface declarations in the compilation pipeline. Types (classes or interfaces) annotated with `[Mapper]` must include the `partial` modifier so the generator can emit the matching implementation.

---

## ❌ Violation Example

```csharp
[Mapper]
public static class UserMapper // Violation: Missing 'partial' keyword
{
    public static partial UserDto ToDto(User entity);
}
```

---

## ✅ Compliant Example

```csharp
[Mapper]
public static partial class UserMapper // Compliant: 'partial' modifier present
{
    public static partial UserDto ToDto(User entity);
}
```

---

## 🛠️ Automated Code Fix

The Roslyn analyzer provides an automated quick-fix (`MakePartialCodeFixProvider`) that automatically adds the `partial` keyword to the type declaration.
