# ELM002: Missing Factory or Constructor

| Property | Value |
|---|---|
| **Rule ID** | `ELM002` |
| **Category** | `EricksonLopez.Mapper.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Destination types in mapping methods |

---

## 🎯 Rule Description

In Native AOT and zero-reflection environments, the source generator must instantiate destination objects using public constructors, parameterless constructors, or designated static factory methods (`[MapFactory]`). 

If a destination type has only `private` or `internal` constructors without an accessible factory method, the generator cannot instantiate the target type at compile time, raising `ELM002`.

---

## ❌ Violation Example

```csharp
public sealed class Money
{
    // Violation: Constructor is private, no [MapFactory] or public constructor available
    private Money(decimal amount, string currency)
    {
        Amount = amount;
        Currency = currency;
    }

    public decimal Amount { get; }
    public string Currency { get; }
}

[Mapper]
public static partial class FinanceMapper
{
    public static partial Money ToDomain(MoneyDto dto);
}
```

---

## ✅ Compliant Example (Option A: Explicit Factory Method)

```csharp
public sealed class Money
{
    private Money(decimal amount, string currency)
    {
        Amount = amount;
        Currency = currency;
    }

    public decimal Amount { get; }
    public string Currency { get; }

    public static Money Create(decimal amount, string currency) => new(amount, currency);
}

[Mapper]
public static partial class FinanceMapper
{
    [MapFactory(nameof(Money.Create))]
    public static partial Money ToDomain(MoneyDto dto);
}
```

---

## ✅ Compliant Example (Option B: Public Constructor)

```csharp
public sealed class Money
{
    public Money(decimal amount, string currency)
    {
        Amount = amount;
        Currency = currency;
    }

    public decimal Amount { get; }
    public string Currency { get; }
}
```
