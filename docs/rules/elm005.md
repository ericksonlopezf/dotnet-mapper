# ELM005: Ambiguous Property Match

| Property | Value |
|---|---|
| **Rule ID** | `ELM005` |
| **Category** | `EricksonLopez.Mapper.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Source types with multiple case-insensitively identical members |

---

## 🎯 Rule Description

Emitted when the source type contains multiple property members that match a destination property name under case-insensitive resolution (e.g., `UserId` and `USERID`, or `total` and `Total`). The generator requires disambiguation to prevent arbitrary member selection.

---

## ❌ Violation Example

```csharp
public sealed class OrderSource
{
    public decimal Total { get; set; }
    public decimal total { get; set; }
}

public sealed record OrderDestination(decimal Total);

[Mapper]
public static partial class OrderMapper
{
    // Violation: Multiple source properties match destination member 'Total'
    public static partial OrderDestination Map(OrderSource source);
}
```

---

## ✅ Compliant Example

```csharp
[Mapper]
public static partial class OrderMapper
{
    [MapProperty(nameof(OrderDestination.Total), nameof(OrderSource.Total))]
    public static partial OrderDestination Map(OrderSource source);
}
```
