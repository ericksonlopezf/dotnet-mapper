# ELM011: Incomplete Polymorphism on Abstract Base Type

| Property | Value |
|---|---|
| **Rule ID** | `ELM011` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Warning` |
| **Enabled by Default** | `true` |
| **Applies to** | Polymorphic hierarchy mappings using `[MapDerivedType]` |

---

## 🎯 Rule Description

Emitted when mapping an abstract base class or interface where not all concrete derived subtypes in the compilation have registered `[MapDerivedType]` branches. If an unmapped derived instance is passed at runtime, fallback handling or an exception will occur.

---

## ❌ Violation Example

```csharp
public abstract record PaymentMethod;
public sealed record CreditCard : PaymentMethod;
public sealed record BankTransfer : PaymentMethod;

public abstract record PaymentMethodDto;
public sealed record CreditCardDto : PaymentMethodDto;
public sealed record BankTransferDto : PaymentMethodDto;

[Mapper]
public static partial class PaymentMapper
{
    // Warning: Base type 'PaymentMethod' is abstract and 'BankTransfer' derived type is not mapped
    [MapDerivedType(typeof(CreditCard), typeof(CreditCardDto))]
    public static partial PaymentMethodDto ToDto(PaymentMethod method);
}
```

---

## ✅ Compliant Example

```csharp
[Mapper]
public static partial class PaymentMapper
{
    [MapDerivedType(typeof(CreditCard), typeof(CreditCardDto))]
    [MapDerivedType(typeof(BankTransfer), typeof(BankTransferDto))]
    public static partial PaymentMethodDto ToDto(PaymentMethod method);
}
```
