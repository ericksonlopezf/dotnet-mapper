# ELM008: Mapper Uses Reflection

| Property | Value |
|---|---|
| **Rule ID** | `ELM008` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Types decorated with `[Mapper]` or mapping helper methods |

---

## 🎯 Rule Description

`EricksonLopez.Mapper` is architected as an **AOT-First, Zero-Reflection** compiler tool. Calling reflection APIs (such as `System.Activator.CreateInstance`, `Type.GetProperties()`, `MethodInfo.Invoke()`, or `FormatterServices`) within mapping classes directly breaks Native AOT trimming invariants and causes runtime crashes in single-file published executables.

`ELM008` is emitted by the Roslyn analyzer to statically prohibit reflection calls in mapper files.

---

## ❌ Violation Example

```csharp
[Mapper]
public static partial class CustomMapper
{
    public static TDest CustomMap<TSource, TDest>(TSource source)
    {
        // Violation: Activator and Reflection are prohibited
        var dest = Activator.CreateInstance<TDest>();
        return dest;
    }
}
```

---

## ✅ Compliant Example

```csharp
[Mapper]
public static partial class CustomMapper
{
    // Compliant: Concrete compile-time partial method generated by Roslyn
    public static partial OrderDto ToDto(Order entity);
}
```
