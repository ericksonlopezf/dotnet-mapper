# ELM010: Circular Mapping Reference

| Property | Value |
|---|---|
| **Rule ID** | `ELM010` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Recursive object graphs |

---

## 🎯 Rule Description

Emitted when the generator detects a cyclic reference chain across nested objects (e.g. `Parent` $\rightarrow$ `Child` $\rightarrow$ `Parent`) without depth limiting. In unrolled static compilation, unchecked recursive mapping would result in an infinite loop and runtime `StackOverflowException`.

---

## ❌ Violation Example

```csharp
public sealed class Node
{
    public string Name { get; set; } = string.Empty;
    public Node? Next { get; set; }
}

public sealed class NodeDto
{
    public string Name { get; set; } = string.Empty;
    public NodeDto? Next { get; set; }
}

[Mapper]
public static partial class NodeMapper
{
    // Violation: Cyclic mapping detected involving method 'ToDto'
    public static partial NodeDto ToDto(Node node);
}
```

---

## ✅ Compliant Example (Break Cycle via MapIgnore or Depth Limit)

```csharp
[Mapper]
public static partial class NodeMapper
{
    [MapIgnore(nameof(NodeDto.Next))]
    public static partial NodeDto ToFlatDto(Node node);
}
```
