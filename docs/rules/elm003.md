# ELM003: Unsupported Conversion

| Property | Value |
|---|---|
| **Rule ID** | `ELM003` |
| **Category** | `EricksonLopez.Mapper.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Property pairs with incompatible types |

---

## 🎯 Rule Description

Emitted when the source property type cannot be converted to the destination property type using standard C# implicit conversions, explicit numeric conversions, primitive parsing, collection projections, or registered `IConverter<TSource, TDestination>`.

---

## ❌ Violation Example

```csharp
public sealed record Source(Guid TransactionId);
public sealed record Destination(int TransactionId); // Incompatible: Guid to int

[Mapper]
public static partial class TransactionMapper
{
    // Violation: Cannot convert from 'Guid' to 'int' for member 'TransactionId'
    public static partial Destination Map(Source source);
}
```

---

## ✅ Compliant Example (Custom Converter Implementation)

```csharp
public sealed class GuidToIntConverter : IConverter<Guid, int>
{
    public int Convert(Guid source) => source.GetHashCode();
}

[Mapper]
[UseConverter(typeof(GuidToIntConverter))]
public static partial class TransactionMapper
{
    public static partial Destination Map(Source source);
}
```
