# ELM017: MapFactory Method Not Found

| Property | Value |
|---|---|
| **Rule ID** | `ELM017` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Mapping methods decorated with `[MapFactory]` |

---

## 🎯 Rule Description

Emitted when a `[MapFactory("MethodName")]` attribute specifies a factory method that does not exist on the target type, is not `public`, is not `static`, or does not return the expected destination type.

Instead of silently falling back to parameterized or parameterless constructors, the generator emits `ELM017` as a compile-time error to prevent unintentional instantiation paths and subtle runtime defects.

---

## ❌ Violation Example

```csharp
public sealed class OrderAggregate
{
    private OrderAggregate() { }

    // Factory method is named 'Build', but the attribute specifies 'Create'
    public static OrderAggregate Build() => new();
}

[Mapper]
public static partial class OrderMapper
{
    // Violation: Factory method 'Create' was not found as a public static method returning 'OrderAggregate'
    [MapFactory("Create")]
    public static partial OrderAggregate ToDomain(CreateOrderDto dto);
}
```

**Compiler Error:**
> `error ELM017: Factory method 'Create' was not found as a public static method returning 'OrderAggregate' on the target type. Verify the method name and accessibility.`

---

## ✅ Compliant Example

Ensure the factory method name matches an accessible public static method on the target type using `nameof(...)`:

```csharp
[Mapper]
public static partial class OrderMapper
{
    [MapFactory(nameof(OrderAggregate.Build))]
    public static partial OrderAggregate ToDomain(CreateOrderDto dto);
}
```
