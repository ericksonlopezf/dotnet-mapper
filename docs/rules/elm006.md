# ELM006: Missing Constructor Mapping

| Property | Value |
|---|---|
| **Rule ID** | `ELM006` |
| **Category** | `EricksonLopez.Mapper.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Target types without matching constructor parameters or public setters |

---

## 🎯 Rule Description

Emitted when a destination type declares parameterized constructors, but the source type cannot satisfy all required constructor parameters, and the destination type does not expose accessible property setters or an alternative parameterless constructor.

---

## ❌ Violation Example

```csharp
public sealed class CustomerDto
{
    public CustomerDto(Guid id, string fullName, DateTime registeredAt) // Requires 3 params
    {
        Id = id;
        FullName = fullName;
        RegisteredAt = registeredAt;
    }

    public Guid Id { get; }
    public string FullName { get; }
    public DateTime RegisteredAt { get; }
}

public sealed record CustomerEntity(Guid Id, string FullName); // Missing RegisteredAt

[Mapper]
public static partial class CustomerMapper
{
    // Violation: Destination type does not have a supported constructor or public setters
    public static partial CustomerDto ToDto(CustomerEntity entity);
}
```

---

## ✅ Compliant Example

```csharp
[Mapper]
public static partial class CustomerMapper
{
    [MapProperty(nameof(CustomerDto.RegisteredAt), "DateTime.UtcNow")]
    public static partial CustomerDto ToDto(CustomerEntity entity);
}
```
