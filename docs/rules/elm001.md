# ELM001: Unmapped Destination Member

| Property | Value |
|---|---|
| **Rule ID** | `ELM001` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Partial mapping methods inside types decorated with `[Mapper]` |

---

## 🎯 Rule Description

`EricksonLopez.Mapper` operates on a strict **fail-fast, compile-time safety** philosophy. If a target property or constructor parameter on the destination type has no corresponding matching source member and is not explicitly ignored via `[MapIgnore]`, provided via `[MapProperty]`, or supplied via `[MapValue]`, `ELM001` is emitted at compile time.

This prevents silent data loss or partially initialized destination models from escaping into production systems.

---

## ❌ Violation Example

```csharp
public sealed record UserDto(Guid Id, string Name, string Email, string PhoneNumber);

public sealed record UserEntity(Guid Id, string Name, string Email); // Missing PhoneNumber

[Mapper]
public static partial class UserMapper
{
    // Violation: Destination member 'PhoneNumber' has no corresponding source mapping
    public static partial UserDto ToDto(UserEntity entity);
}
```

**Compiler Error:**
> `error ELM001: Destination member 'PhoneNumber' has no source mapping`

---

## ✅ Compliant Example (Option A: Explicit Value / Property Mapping)

```csharp
[Mapper]
public static partial class UserMapper
{
    [MapValue(nameof(UserDto.PhoneNumber), "\"N/A\"")]
    public static partial UserDto ToDto(UserEntity entity);
}
```

---

## ✅ Compliant Example (Option B: Explicit Member Ignore)

```csharp
[Mapper]
public static partial class UserMapper
{
    [MapIgnore(nameof(UserDto.PhoneNumber))]
    public static partial UserDto ToDto(UserEntity entity);
}
```

---

## 🛠️ Automated Code Fixes & Roslyn Integration

The analyzer provides two automated code fix actions in Visual Studio / JetBrains Rider / VS Code:
1. **Add `[MapProperty(nameof(Member), "")]` attribute**: Generates custom mapping attribute on the partial method.
2. **Add `[MapIgnore(nameof(Member))]` attribute**: Generates ignore attribute to declare the omission as intentional.
