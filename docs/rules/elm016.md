# ELM016: Direct String to Enum Parsing Runtime Exception Risk

| Property | Value |
|---|---|
| **Rule ID** | `ELM016` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Warning` |
| **Enabled by Default** | `true` |
| **Applies to** | `string` to `enum` conversions |

---

## 🎯 Rule Description

Emitted when mapping directly from an unconstrained `string` property to a strongly-typed `enum`. If the runtime string value does not match any member of the target enumeration, `Enum.Parse` or `Enum.TryParse` fallback logic will trigger.

---

## ❌ Violation Example

```csharp
public enum OrderStatus { Pending, Paid, Shipped }

public sealed record RawMessage(string Status);
public sealed record OrderEvent(OrderStatus Status);

[Mapper]
public static partial class EventMapper
{
    // Warning: Direct string-to-enum parsing for member 'Status' can fail at runtime
    public static partial OrderEvent Map(RawMessage message);
}
```

---

## ✅ Compliant Example (Option A: Custom Converter with Safe Fallback)

```csharp
public sealed class StringToOrderStatusConverter : IConverter<string, OrderStatus>
{
    public OrderStatus Convert(string source) =>
        Enum.TryParse<OrderStatus>(source, ignoreCase: true, out var status) ? status : OrderStatus.Pending;
}

[Mapper]
public static partial class EventMapper
{
    [UseConverter(typeof(StringToOrderStatusConverter))]
    public static partial OrderStatus ParseStatus(string source);

    public static partial OrderEvent Map(RawMessage message);
}
```

---

## ✅ Compliant Example (Option B: Strongly-Typed Domain Enums)

Prefer using enum types directly in message contracts instead of unconstrained strings to ensure full compile-time type safety.
