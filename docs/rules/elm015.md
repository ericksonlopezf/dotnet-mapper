# ELM015: Narrowing Numeric Conversion Potential Data Loss

| Property | Value |
|---|---|
| **Rule ID** | `ELM015` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Warning` |
| **Enabled by Default** | `true` |
| **Applies to** | Numeric member conversions (e.g., `long` $\rightarrow$ `int`, `double` $\rightarrow$ `float`) |

---

## 🎯 Rule Description

Emitted when a mapping method converts a wider numeric type to a narrower numeric type (for example, `long` to `int` or `decimal` to `double`). While the generator automatically emits checked explicit casts, this warning alerts developers to potential numeric overflow or loss of precision.

---

## ❌ Violation Example

```csharp
public sealed record Source(long LargeCounter);
public sealed record Destination(int LargeCounter); // Narrowing conversion

[Mapper]
public static partial class MetricsMapper
{
    // Warning: Narrowing numeric conversion from 'long' to 'int'
    public static partial Destination Map(Source source);
}
```

---

## ✅ Compliant Example

Align numeric types across models or acknowledge the conversion explicitly:

```csharp
public sealed record Destination(long LargeCounter);
```
