# ELM004: Nullability Mismatch

| Property | Value |
|---|---|
| **Rule ID** | `ELM004` |
| **Category** | `EricksonLopez.Mapper.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Nullable source members mapping to non-nullable destination members |

---

## 🎯 Rule Description

Emitted when a nullable source member (e.g., `string?` or `int?`) is mapped to a non-nullable destination member (e.g., `string` or `int`) without an explicit fallback value or null-coalescing strategy. This diagnostic preserves strict C# 8.0+ Nullable Reference Type invariants across domain and DTO boundaries.

---

## ❌ Violation Example

```csharp
public sealed record Source(string? Nickname);
public sealed record Destination(string Nickname); // Non-nullable

[Mapper]
public static partial class UserMapper
{
    // Violation: Possible null reference assignment for member 'Nickname'
    public static partial Destination Map(Source source);
}
```

---

## ✅ Compliant Example (Option A: Explicit Null Fallback)

```csharp
[Mapper]
public static partial class UserMapper
{
    [MapNullFallback(nameof(Destination.Nickname), "Anonymous")]
    public static partial Destination Map(Source source);
}
```

---

## ✅ Compliant Example (Option B: Nullable Destination)

```csharp
public sealed record Destination(string? Nickname);
```
