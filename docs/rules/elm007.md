# ELM007: Ambiguous Constructor

| Property | Value |
|---|---|
| **Rule ID** | `ELM007` |
| **Category** | `EricksonLopez.Mapper` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Destination types with multiple parameterized constructors |

---

## 🎯 Rule Description

Emitted when a destination class has multiple parameterized constructors that match different subsets of source properties. The generator requires an explicit `[MapFactory]` selection directing instantiation to a static factory method to prevent non-deterministic instantiation paths.

---

## ❌ Violation Example

```csharp
public sealed class OrderAggregate
{
    public OrderAggregate(Guid id, string customerId) { ... }
    public OrderAggregate(Guid id, string customerId, decimal total) { ... }

    public static OrderAggregate Create(Guid id, string customerId, decimal total) => new(id, customerId, total);
}

[Mapper]
public static partial class OrderMapper
{
    // Violation: Multiple parameterized constructors available
    public static partial OrderAggregate ToDomain(CreateOrderDto dto);
}
```

---

## ✅ Compliant Example

```csharp
[Mapper]
public static partial class OrderMapper
{
    [MapFactory(nameof(OrderAggregate.Create))]
    public static partial OrderAggregate ToDomain(CreateOrderDto dto);
}
```

---

## 🛠️ Automated Code Fix

The Roslyn analyzer provides an automated quick-fix (`MapFactoryCodeFixProvider`) that automatically adds `[MapFactory("Create")]` to the mapping method declaration.
