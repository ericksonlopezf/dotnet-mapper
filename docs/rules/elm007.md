# ELM007: Ambiguous Constructor

| Property | Value |
|---|---|
| **Rule ID** | `ELM007` |
| **Category** | `EricksonLopez.Mapper.Design` |
| **Severity** | `Error` |
| **Enabled by Default** | `true` |
| **Applies to** | Destination types with multiple parameterized constructors |

---

## 🎯 Rule Description

Emitted when a destination class has multiple parameterized constructors that match different subsets of source properties. The generator requires an explicit `[MapConstructor]` or `[MapFactory]` selection to prevent non-deterministic instantiation paths.

---

## ❌ Violation Example

```csharp
public sealed class OrderAggregate
{
    public OrderAggregate(Guid id, string customerId) { ... }
    public OrderAggregate(Guid id, string customerId, decimal total) { ... }
}

[Mapper]
public static partial class OrderMapper
{
    // Violation: Multiple parameterized constructors available
    public static partial OrderAggregate ToDomain(CreateOrderDto dto);
}
```

---

## ✅ Compliant Example

```csharp
[Mapper]
public static partial class OrderMapper
{
    [MapConstructor(nameof(Guid), nameof(String), nameof(Decimal))]
    public static partial OrderAggregate ToDomain(CreateOrderDto dto);
}
```
