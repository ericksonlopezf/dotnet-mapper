# Support & Getting Help

Welcome to the `EricksonLopez.Mapper` community. If you need help, encounter an issue, or want to explore enterprise support, this guide outlines the available channels.

---

## 1. Community Support (Free)

For general usage questions, troubleshooting, and design advice, please leverage our public community channels:

### GitHub Discussions

The primary channel for questions and community ideas is [GitHub Discussions](https://github.com/ericksonlopezf/dotnet-mapper/discussions):
- **Q&A**: Ask implementation and mapping pattern questions.
- **Ideas & RFCs**: Propose new features or discuss enhancements before creating an issue.
- **Show and Tell**: Share how you use the library in production.

### GitHub Issues (Bugs & Regressions Only)

If you encounter a reproducible defect or compiler diagnostic error:
- Open a [GitHub Issue](https://github.com/ericksonlopezf/dotnet-mapper/issues).
- Provide a minimal reproducible example (C# snippet or sample repo).
- Specify your .NET SDK version, target framework, and NativeAOT status.
- *Note:* Do not use GitHub Issues for general programming help or support questions.

## 2. Enterprise Support & Architectural Consulting

If your organization relies on `EricksonLopez.Mapper` in mission-critical environments and requires commercial support:

- **Custom Integrations**: Tailored converter packages for internal frameworks.
